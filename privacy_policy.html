MH-Quantum Inspector

Privacy Policy

100% Local Processing

Data Collection

MH-Quantum Inspector accesses tab and element styling details solely for local code analyses. The extension collects:

  • DOM structure and CSS selectors of inspected elements
  • Computed styles (colors, layout, typography) for the selected element
  • Element geometry and stacking context

All collected data is used exclusively to generate AI-ready context payloads for developer workflows.

1. Data Collection & Transmission

This extension operates entirely locally. It does not send any data to external servers or cloud services.

When you use the "Connect to MCP Server" feature, the extension communicates strictly with your local machine via HTTP on http://127.0.0.1:3747/sync — data never leaves your machine.

No Remote Telemetry

All data processing is conducted locally on your machine. MH-Quantum Inspector does not transmit any data to external servers, cloud services, or remote endpoints.

No Tracking

  • No analytics or usage tracking of any kind
  • No cookies or persistent identifiers
  • No user behavior monitoring
  • No advertising or marketing data collection

No Third-Party Services

MH-Quantum Inspector operates entirely independently. It does not integrate with, send data to, or receive data from any third-party services, APIs, or platforms.

Permissions Used

  • activeTab — Access the current tab to inspect element details
  • storage — Persist user preferences locally
  • contextMenus — Provide right-click menu integration
